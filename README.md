# Line Comparison Problem

## Overview

The **Line Comparison Problem** is a Java application that demonstrates the use of object-oriented programming concepts to model geometric lines using Cartesian coordinates. The application calculates the length of lines, checks equality, and compares line lengths using Java's built-in methods.

## Features

* Display a welcome message.
* Calculate the length of a line using Cartesian coordinates.
* Check the equality of two lines using the `equals()` method.
* Compare two line lengths using the `compareTo()` method.
* Implement object-oriented design using `Point` and `Line` classes.

## How to Run

1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile the source files.
4. Run the `LineComparison.java` file.
5. Enter the coordinates of two lines when prompted.
